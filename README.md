# Blender Production System (BPS)

> An open-source Blender production framework for asset validation, certification, rigging readiness, and animation workflow automation.

---

## Overview

Blender Production System (BPS) is an open-source toolkit designed to help independent creators and small studios build production-ready Blender projects using professional workflow standards.

The project provides automated quality assurance tools, production audits, certification reports, naming validation, and workflow organization to improve consistency throughout the animation pipeline.

BPS was inspired by the real production pipeline developed while creating **Kyro & Nyla's Learning Adventures**, an educational preschool animation series.

---

## Vision

Bring professional production pipeline tools to every Blender creator.

Whether you're building a single character or an entire animated series, BPS helps you organize, validate, and certify your work before it moves to the next production phase.
